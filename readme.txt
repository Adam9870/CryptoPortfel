Instrukcja uruchomienia projektu

--- WYMAGANIA ---
1. Zainstalowana Java (najlepiej wersja 17 lub nowsza) oraz poprawnie ustawiona zmienna srodowiskowa JAVA_HOME.
2. Zainstalowany Node.js (do uruchomienia frontendu).

--- KROK 1: URUCHOMIENIE BACKENDU (SPRING BOOT) ---
1. Nowe okno cmd
2. cd backend-strategy
3. mvnw.cmd clean spring-boot:run

--- KROK 2: URUCHOMIENIE FRONTENDU (REACT) ---
1. Nowe okno cmd
2. cd frontend
3. npm install
4. npm run dev
